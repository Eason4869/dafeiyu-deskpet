# 制作自己的桌宠

0.5.3 dev 预览同时支持本目录的 v1 单图模板，以及 `high-fps-v2/` 的 v2 分动作高帧模板。v2 中的 PNG 是空白制作画布，必须画完全部动作和视线后再导入；详见其 `先读我.md`。两种格式均选择对应目录里的 `pet.json` 导入。高帧模板是作者创作工具；当前预设伙伴使用低帧原画动画，不代表已经采用模板中的高帧播放参数。

1. 复制本文件夹到一个新目录。
2. spritesheet.png 是可导入的大肥鱼示例布局，换成自己的 8 列 × 11 行透明 PNG。推荐完整尺寸 3840×5720，每格 480×520。帧顺序看 grid-guide.svg，可以用浏览器打开。
3. 用文本编辑器修改 pet.json 的名称、简介及 system_prompt 人格；atlas 写同目录的 PNG 文件名。
4. 设置 → 伙伴 → 伙伴与人格 → 导入外观 → 选择 pet.json。
5. 到“人格”页继续调整。恢复模板预设会恢复导入时的设定。

ZIP 外观包先解压。单独导入 PNG 时，名称取文件名、人格使用通用预设。pet.schema.json 提供字段说明；网格 SVG 只是参考，不能直接导入。

详细教程：../docs/skin-format.md。每行有效帧数：6、8、8、4、5、8、6、6、6、8、8，其余格透明。


本次仅更新 dev 分支与版本标签，尚未发布 0.5.3 Release 或独立模板 ZIP。完整 v2 作者模板已包含在本仓库 `high-fps-v2/` 中，无需其他目录。先完成画布再导入，空白模板不是可直接使用的伙伴。
