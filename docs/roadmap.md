# 开发路线图

0.5.6 先发布 Windows 功能更新；macOS 由独立工作区并行开发，在 0.6.0 增加两架构适配并规范包名，业务功能以 0.5.6 为基线；该版先推代码、PR 和标签，暂不创建 Release。最初的 0.5.5 状态保留在 [快照说明](https://github.com/Eason4869/deskpet/blob/dev/docs/0.5.5-dev-checkpoint.md)，Mac 设计与验收要求见 [设计](https://github.com/Eason4869/deskpet/blob/dev/docs/macos-design.md)。

以下为待开发需求；标注 **[待确认]** 的部分需要进一步设计，不代表当前版本已支持。

## 好感度系统

- [ ] 设计每位伙伴独立的好感度系统，让日常陪伴和互动形成持续反馈。
- [ ] **[待确认] 呈现方式**：使用数值、关系阶段、表情／动作或台词变化；是否向用户直接展示好感度。
- [ ] **[待确认] 运行模式**：抚摸、投喂、聊天、陪伴时长等行为是否影响好感度，以及增长上限、冷却、是否衰减和长期未使用时的处理方式。
- [ ] **[待确认] 反馈与保存**：不同阶段是否解锁专属台词或动作；明确本地保存、切换伙伴、重启及重置规则。

## 拖动放下后的概率踉跄

- [x] 在现有“拎起 → 放下”交互中加入概率触发的踉跄动作，短暂站不稳后恢复待机（0.5.6 发布）。
- [x] 仅在实际拖动并松开后判定，普通点击不触发；处理连续拖动、中断、暂停、隐藏及伙伴切换。
- [x] 固定 40% 概率，触发后冷却 10 秒；“陪伴方式”提供开关。
- [x] 四位内置伙伴均适配 8 姿态、8 FPS 的踉跄；自定义外观缺少素材时保持普通落地。

## 节日限定服饰与动作

- [ ] 在特殊节日当天解锁对应服饰和动作，并提供节日提示与选择入口。
- [ ] **中秋节**：制作／赠送赛博月饼的互动与动作。
- [ ] **端午节**：制作／赠送赛博粽子的互动与动作。
- [ ] **万圣节**：节日新衣与配套动作。
- [ ] 支持公历节日与农历节日识别，明确按本地日期判定；覆盖跨日运行和节日当天重新启动的情况。
- [ ] **[待确认] 解锁规则**：是否必须当天启动或互动领取，解锁后永久保留还是仅当天可用，错过后是否支持次年再次获取。
- [ ] 分别适配各伙伴的节日素材；自定义外观缺少素材时保留原外观和基础动作。
- [x] 预留悬停节日动作接口：`IHolidayHoverActionProvider` 按伙伴与本地日期返回一个可播放动作，有效时追加到四项常规候选中；未接入具体节日、服饰、领取或解锁机制。详见 [互动扩展](interaction-extension.md)。

建议推进顺序：先完成拖动踉跄，再确定好感度方案；节日功能按“日期识别与解锁规则 → 单个节日试做 → 扩充素材”逐步推进。
