# 文字、语音与 Live 设置（0.5.2）

完整聊天和快速气泡中，**左上角缩略图旁的喇叭图标**控制 TTS 输出，与 AI 配置 → 声音与朗读中的 **TTS 输出** 开关同步并保存。关闭时停止当前朗读或合成；等待模型回复时关闭会跳过后续朗读，文字回复照常保留。该开关控制分步 TTS，Live 原生音频随 Live 会话输出。

右键桌宠 → **设置** → **AI 配置**，也可从完整聊天进入连接设置。设置左侧有“伙伴、AI 配置、快捷键、关于”四项；AI 配置内分为 **文字模型、语音识别、声音与朗读、Live 实时语音** 四个页签。地址、模型和密钥需点 **保存服务设置**；切换页签保留未保存草稿，保存后再切换伙伴。启动不会请求模型或打开麦克风。

首次启动提供 16 步引导：伙伴、人格、陪伴方式、拖动、右键菜单、中键轮盘、单击互动、双击快速对话、文字模型、语音识别、回复朗读、Live、主动问候、快捷键、对话与队列、更新与网络加速。仅当前项可操作，其余区域灰显锁定；必填项未完成或实操未达成时，“下一步”不可点击。桌面实操期间暂时收起设置，避免遮挡宠物。

“跳过这一步”只跳过当前项并进入下一步，未保存草稿留在设置页；“跳过引导”或关闭引导结束整个流程并恢复正常操作。设置左下方“配置引导”可重新开始；已有配置升级后不会自动弹出。

## 文字与人格

在 AI 配置 → “文字模型”选常用服务预设，或手动填地址、模型、API 密钥。默认 **OpenAI Chat Completions**；兼容 Claude 的服务可选 **Anthropic Messages**。地址保留 /v1 或服务规定的前缀；程序分别拼接 /chat/completions 或 /messages，也接受完整端点。Anthropic 请求使用 x-api-key、anthropic-version、独立 system 与 max_tokens。

远程服务需 HTTPS，本机可用 http://127.0.0.1:端口/v1 且可无密钥。预设是填表的示例，不保证账号拥有该模型；火山部署 ID 与智谱模型需自行填写。MiMo Token Plan 用户可选择国内 Token Plan 预设，使用对应服务的密钥。

每项服务都有 **使用代理连接** 开关，默认关闭；**代理地址** 默认 `http://127.0.0.1:7890`，可编辑并随服务设置保存。支持 `host:port`、`http://host:port` 及 IPv6 地址，如 `[::1]:7890`，使用 HTTP 代理协议；不支持 SOCKS 或带账号、路径、密钥的代理地址。开启后需有该地址的代理运行，关闭后直接连接。ASR/TTS 复用文字服务时同时继承其代理开关和地址。切换预设或手动改到其他服务域名、协议、端口时会清空旧 API 密钥；同一服务内修改地址路径可保留密钥。

聊天 Enter 发送、Shift+Enter 换行，每条最多 8000 字；支持停止、复制回复和清空。双击角色可在头顶气泡直接输入，展开聊天查看完整内容。文字默认流式显示，气泡与完整窗口同步；在文字模型页可关闭“流式回复”。回复完成后才进行 TTS。停止或断线保留部分文字并标注未完成。

每位伙伴各有独立人格与加密历史；发送文字请求时只携带最近 10 轮完整成功会话及有界上下文。切换伙伴同步切换；正在对话需先停止。E包预设使用用户指定的白发正太人格。编辑只影响当前伙伴；保存或恢复预设后清空当前伙伴上下文。默认退出后恢复历史，可在“快捷键”关闭保存。清空当前会话也清除该伙伴的磁盘记录。关闭气泡不会取消气泡发起的请求。

## ASR + TTS

“语音识别”填识别模型、协议、地址及密钥。“声音与朗读”选 Windows 系统语音，或打开云端 TTS 并填模型与音色。两项均可独立勾选复用文字服务的地址、密钥和代理，模型仍单独设置。

**MiMo**：协议选自动或 MiMo Chat Audio；识别模型 mimo-v2.5-asr，合成 mimo-v2.5-tts。MiMo 在 /chat/completions 使用音频输入与 Base64 音频输出。音色可用苏打、白桦、冰糖、茉莉或 mimo_default 等服务支持名称。Token Plan 是否开放所用模型以账号权限为准。

**OpenAI Audio**：ASR 上传 WAV multipart 到 /audio/transcriptions，返回 JSON text；TTS 向 /audio/speech 请求 WAV。其他服务须兼容对应协议，不能将只支持文字的模型填进语音页。

快速对话和完整聊天都在输入框右侧提供 **听写** 图标，位于主按钮左边。点击后显示真实收音波形；至少说半秒后，点 **停止听写** 会识别并追加到原草稿，点 **发送听写** 则识别后连同原草稿发送，AI 忙碌时排队。Esc 或隐藏／关闭窗口取消听写。最长 60 秒，到时自动结束并填入草稿，不自动发送。听写与 AI 回复独立运行；麦克风采用 16kHz 单声道 PCM，原录音只在内存。

音量默认 50%，更改立即生效并保存，0% 静音；自动朗读可关闭。试听先保存连接设置并朗读问候。朗读失败保留文字，显示具体服务错误。云端 WAV 临时放在 data/audio-cache，完成或取消时删除。

## Gemini Live

“Live 实时语音”选 Gemini Live 预设，填写自己的模型、密钥、音色（例如 Kore）。完整 WSS 地址：

`wss://generativelanguage.googleapis.com/ws/google.ai.generativelanguage.v1beta.GenerativeService.BidiGenerateContent`

示例模型 gemini-3.8-live，以账号实际可用模型为准。Live 使用原生 WebSocket，与文字页面的 Gemini OpenAI 地址不同。代理单独设置。

在输入框为空且 AI 空闲时，点击快速对话或完整聊天右侧的 **通话声波按钮**，在原窗口内覆盖显示通话界面并尝试连接；快速对话为紧凑布局，完整对话为大布局。服务器确认初始化后才打开麦克风，持续传输 16kHz PCM，直接播放返回 PCM。通话窗口显示伙伴头像、输入和回复字幕；环形波形由实际输入／输出音量驱动，安静时收拢，完成轮次加入当前伙伴记录。语音打断会清除播放缓冲。Live 使用当前伙伴人格，独立建立连接，不自动将原文字聊天历史上传到 Live。

在通话窗口点击 **挂断图标**、**返回文字对话图标**或关闭窗口，会结束网络、录音和播放；聊天中的“停止”也可结束当前语音。Live 期间文字、ASR 流程、切换伙伴和语音模式暂停，结束后恢复。通话结束后返回发起它的快速或完整对话，保留输入草稿；关闭承载通话的窗口或退出桌宠会结束通话。连接失败时可以打开“AI 配置”调整，随后点击“重新连接”。建议使用耳机，避免外放声音被重复拾取。

## 故障定位

401/403：密钥或模型权限；404：地址前缀与模型名；429：额度或频率；MiMo 不返回文字或音频：检查 ASR/TTS 模型、协议和音色。无录音：检查 Windows 默认输入设备及桌面应用麦克风权限。无声音：检查默认输出设备、音量与已安装的中文 Windows 音色。

HTTP 请求含响应体总超时 120 秒，Live 初始化约 25 秒，可随时停止。错误摘要不展示服务原始响应或密钥。密钥由 Windows 当前用户 DPAPI 加密，换机器或账户需重新填写。应用不能读取桌面或自动上传文件；用户发送的文字和录音交给配置的服务。

服务能否连接、模型权限和实际声音取决于你的账号、网络及设备；可先发送一条短消息或在“声音与朗读”中试听。

## 音色预设

TTS 和 Live 音色可下拉选择，也可手动填写。选厂商与模型后列表显示匹配的 Voice ID 和简短说明；选择保存时只提交 ID，不包含说明。音色按当前伙伴与服务地址、协议、模型分别保存。首次进入某个服务时提供该伙伴的推荐音色；保存过的下拉选择或手写 ID 优先恢复。切换到其他服务不会把前一个服务的自定义 ID 直接带过去，切回来可恢复原选择。未保存的切换草稿在当前设置窗口内保留。未知模型仍可手动填写。完整来源与范围见[音色预设依据](voice-presets.md)。
