最终独立审查发现三项需要修复的问题：手动改服务域名仍保留旧密钥；Live 中从设置切换模式后可能打开第二条录音流程；失败下载误删已有 .part。三项均先观察回归失败，再修复。现在所有服务编辑器按密钥所属地址清除跨域密钥；对话期间拒绝切换语音模式，“结束 Live”按实际连接状态处理；下载使用独有临时文件且仅清理自己创建的文件。另补充版本比较回归，避免把 1.2.0 和 1.2.0.0 误判为新旧版本。

界面截图来自实际 WPF 窗口；运行程序截图来自本机 Windows。原生鼠标检查会恢复光标，外部鼠标操作干扰的轮次需重试。已检查默认麦克风、输出设备和系统语音；测试录音保留在内存，未上传在线服务。

尚未验收：真实 MiMo/Gemini Live 等账号的模型权限、联网可达性和声音质量；真实 GitHub 仓库及安装包（仓库尚为占位）；混合 DPI 多屏移动、设备热拔插、其他 Windows 版本/驱动和语音包。在线请求格式与本地设备通过不代表上述项目已通过。GitHub 查询与下载已通过本地模拟服务，当前仍交付免安装版。

运行 ZIP 不含 data、密钥或聊天记录；源码 ZIP 不含 work 或测试设置。包装脚本检查高清素材、全部 ZIP 完整性，以及运行 ZIP 内 EXE 与交付 EXE 的 SHA256 一致。模板包含可导入示例 pet.json / PNG、JSON Schema 和动作网格图。两份高清外观 ZIP 各带独立预设人格。
