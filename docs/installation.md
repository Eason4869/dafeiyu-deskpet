# 安装、升级与自启

Windows 10/11 x64，需 .NET Framework 4.8 或更新版本。下载来自 [GitHub Releases](https://github.com/Eason4869/deskpet/releases/latest)。

## 安装

运行 DeskPet-Setup-0.5.0.exe，按中文向导安装到当前用户目录，默认 `%LOCALAPPDATA%\Programs\DafeiyuDeskPet`。不要求管理员权限；可选桌面快捷方式，开始菜单有启动和卸载入口。首次使用默认 E包，另外内置大肥鱼与马尔芙。首次启动会打开六步新手引导，可直接填写真实设置，也可稍后或跳过；设置左下方“新手引导”可重开。已有配置升级后不会自动弹出。

安装包没有默认开启自启，也不会调用模型或打开麦克风。自启在设置 → 伙伴与外观 → **开启自启** 中选择；开关立即应用于当前程序路径，关闭后撤销。移动程序文件夹后，请在新位置重新开启自启。

## 升级

0.3.1 将软件名统一为“桌面伙伴”，仓库改为 `Eason4869/deskpet`。从 1.3.x 调整版本编号后，旧版的数字比较不会提示这个较小的版本号，请手动下载当前 0.5.0 安装包安装一次。安装器保留原应用标识和安装目录，迁移本目录已经开启的自启到 `桌面伙伴.exe`，移除旧名称 EXE 和旧名称快捷方式；`data` 保留。新安装默认不开启自启。

免安装版请完整解压到新目录后复制旧版 `data`，或覆盖原目录。旧版开启了自启时，请在新版重新开启，以绑定新的 EXE 名称。不要再从旧名称 EXE 启动。

设置 → 关于与更新 → **检查并更新** 可自动完成下载、SHA256 与长度校验、退出桌宠、覆盖安装和重启，无需手动退出。默认启动 30 秒后自动检查，每 24 小时最多一次，可关闭。下载期间及重启前的 5 秒倒计时可取消；后台更新会在桌宠旁显示倒计时和取消按钮，不抢输入焦点。未发送文字（包括隐藏窗口中的草稿）、进行中的对话或语音、全屏、拖动、未保存设置或聊天记录保存失败会让安装等待；手动更新可自动关闭空闲的聊天与设置窗口，后台更新则等窗口关闭。引导、动作面板或独立 Live 通话窗口打开时也会等待；历史保存失败请先导出重要记录或处理保存问题，更新交接前会再次等待历史写入完成。

安装版根据本安装位置的记录，在原目录静默升级；便携版使用运行 ZIP 替换发行文件，不修改其他安装记录。专用助手等待旧进程退出后执行，不重启 Windows。配置、密钥、导入外观及其他 `data` 保留；便携替换失败恢复原文件并重新打开原版。更新结果显示在关于页，任务包和备份在 `data/updates`。0.4.0 起聊天记录默认按伙伴加密保存，重启后恢复；可在设置中关闭保存。

**0.5.0 提供正式 Release 与安装包。** 0.3.2／0.3.3 开发版可从更新器升级；0.3.1 也可在“关于与更新”检查新版本；旧 1.x.x-beta 用户需要下载安装包完成编号调整。更新器只检查正式 Release，单独的 dev tag 不触发更新。

首次从免安装版迁移：退出原桌宠，将原文件夹的 `data` 复制到新安装目录（首次启动前）。密钥由当前 Windows 用户加密，换用户或机器需重新填写。

## 卸载与备份

使用 Windows 的“已安装的应用”或开始菜单卸载入口。卸载移除程序、快捷方式和指向本安装目录的自启项，保留 `data`。需要彻底清除个人配置时，在确认不再需要后自行删除安装目录中的 `data`；备份则复制该文件夹。

仍提供 **DeskPet-Windows-0.5.0.zip** Windows 免安装包：完整解压到可写目录，运行桌面伙伴.exe。请保留 docs、templates 和 previews 文件夹。免安装版自启绑定解压位置。

安装包当前未做应用代码签名。发布页附 SHA256 校验文件；自动更新要求固定仓库、匹配的版本与附件名称、完整长度及 GitHub 提供的 SHA256 摘要。无法验证时保留原版，提示到 Release 页面查看。

## 旧版更新兼容性

0.4.0 便携包曾包含旧更新助手不支持的 GIF 预览，表现为下载、重启后仍是旧版本。0.4.1 已恢复兼容运行包，可从 0.3.3 直接更新。GitHub README 保留动画，本地文档使用静态图。
