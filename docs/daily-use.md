# 日常使用（0.5.1）

## 初次见面与设置

首次启动提供 13 步引导：伙伴、人格、陪伴方式、拖动、右键菜单、中键轮盘、单击互动、文字模型、语音识别、回复朗读、Live、主动问候与快捷键。仅当前项可操作，其余区域灰显锁定；必填项未完成或实操未达成时，“下一步”不可点击。桌面实操期间暂时收起设置，避免遮挡宠物。

“稍后再设置”只跳过当前项并进入下一步，未保存草稿留在设置页；“跳过引导”或关闭引导结束整个流程并恢复正常操作。设置左下方“新手引导”可重新开始；已有配置升级后不会自动弹出。

设置左侧有四个入口：伙伴、AI 配置、快捷键、关于。AI 配置内再分为文字模型、语音识别、声音与朗读、Live 实时语音。切换页签保留填写草稿；切换伙伴前请先保存修改。

伙伴内分为 **伙伴与人格 / 陪伴方式 / 主动问候**；右键 **外观** 可直接切换伙伴，**设置** 打开详细配置。

## 和伙伴互动

按住角色拖动时，伙伴会悬空并轻轻晃动；松开后落地。单击头部是摸摸头，单击身体是戳一戳；双击仍打开快速对话。单击动作会稍等系统双击间隔，以免把双击误当成两次互动。

右键 → 互动提供摸摸头、戳一戳、喂零食、小憩和专属动作。投喂后伙伴会开心回应；小憩期间不散步、不主动问候，点击“叫醒”或开始其他互动即可唤醒。三位内置伙伴各有一项“专属动作”。这些互动无需 AI，也不会自动播放语音。

**中键点击角色**打开动作轮盘。每项以当前伙伴的缩略图展示，下方有简短名称，悬停可看说明：

- **技能**：喂零食、小憩／叫醒、专属动作。
- **动作**：待机、向右跑、向左跑、招呼、跳跃、委屈、等待、思考、检查成果。

选择后播放并收起。轮盘缝隙等宽，中心可切换技能／动作；滚轮切换分类，方向键选中后按 Enter 播放。中心关闭按钮、再次按中键、Esc 或点击外部均可收起。左右跑是原地演示动作。摸头、戳身体、拖拎和落地直接通过鼠标手势触发，不放入面板；开心是投喂后的自然回应。右键菜单仍可照常使用。对话、语音或更新进行时，等待当前操作结束再播放动作。

锁定位置时仍可单击互动，但不能拖动。暂停动画时不响应单击和拖动动画；主动选择菜单动作可恢复播放。自定义外观继续使用原来的动作格式，互动采用已有动作回应。

## 快速对话、朗读与 Live

双击伙伴打开快速对话，输入后按 Enter 发送，Shift + Enter 换行；点击展开图标进入完整聊天，并自动收起快速对话。两个窗口共享当前伙伴的消息与生成进度。两处输入框左侧均有 Live 与语音输入图标；右侧为发送和停止。红色矢量方框可停止思考、流式输出或朗读，空闲时置灰。

左上角缩略图旁的小喇叭控制 TTS 自动朗读，快速对话、完整聊天和设置中的“TTS 输出”同步。关闭会停止当前朗读，也会跳过还在生成中的回复朗读，文字仍然显示。音色按伙伴和服务模型保存，切换角色后随之切换。

点击快速对话或完整聊天中的 **Live 图形按钮**，会在当前窗口内显示通话界面并尝试连接。连接成功后才打开麦克风；头像周围的环形波形随真实收音和回复音量变化，字幕显示当前发言。点击挂断、返回文字对话或关闭通话窗口可结束。连接失败可进入 AI 配置调整，再重新连接。TTS 喇叭不控制 Live 原生音频。

## 自动更新

设置 → 关于 → 检查并更新：发现正式新版后自动下载并校验，倒计时结束后保存状态、退出、覆盖安装并重启。无需手动退出桌宠。下载和倒计时期间可取消。

未发送的文字（包括隐藏窗口中的输入）、未保存设置、进行中的对话或语音会让安装等待。手动更新可自动关闭空闲聊天和设置窗口；后台更新则等这些窗口关闭后再开始。配置、聊天记录和导入外观保留。

聊天记录保存失败时也会暂停安装，先导出重要记录或处理保存问题，再继续更新。引导或动作轮盘开启时，关闭面板后再等待自动安装。更新交接前会再次检查活动状态并等待历史写入。

## 聊天历史

设置 → 快捷键 → 保存聊天历史，默认开启。文字、ASR 后的对话及 Live 字幕按伙伴保存，恢复时显示以前的记录。完整聊天默认显示最近 50 轮，点击“加载更早记录”继续查看，点击“导出记录”保存 Markdown。清空同时删除当前伙伴的磁盘记录。

每位伙伴保留最近 200 轮且序列化内容最多 8 MiB，超出上限整轮删除最旧记录。模型只收到最近十轮完整成功对话，并按输入长度裁剪；未完成记录仅供查看。Live 打断、停止和异常字幕也保留，标注未完成状态并排除成功上下文。应用异常退出时，最后一次进度检查点恢复为“已中断”。关闭保存后保留已有文件，当前会话仍可在内存中使用。

记录放在程序旁 data/history，使用当前 Windows 用户 DPAPI 加密。换机器或 Windows 账户可能无法解密，原文件会保留并提示；导出的 Markdown 为普通文本。发布包不包含个人 data。保存失败会提示，当前对话继续保留在内存。

## 流式回复

设置 → AI 配置 → 文字模型 → 流式回复，默认开启，需点击“保存服务设置”。快速对话和完整聊天共享同一条回复，文字逐步增长；生成期间打开另一窗口可接着查看。向上阅读历史时不强制滚回底部。

点击停止会取消当前请求；断线或服务错误保留已有文字并显示状态。未完成回复不自动朗读，不作为完整的下一轮模型上下文。接口明确不支持流式时可关闭开关。程序不因流式失败自动发送第二次请求。文字完成后按 TTS 偏好与免打扰状态决定是否朗读。

## 免打扰与桌面行为

免打扰暂停主动问候、散步、自动朗读，并停止当前自动朗读；不修改 TTS 输出开关和音量。主动文字、录音及 Live 可继续使用。

全屏自动隐藏默认开启，只检测伙伴所在屏幕的前台全屏应用。退出全屏时仅恢复自动隐藏的伙伴；手动隐藏一直保留。主动唤出快速对话可暂时覆盖全屏隐藏。隐藏时不渲染动画，定时恢复检测仍运行。

整体鼠标穿透让点击落到下方应用，聊天窗口仍可操作；从托盘或快捷键关闭。锁定位置禁止拖动与散步。托盘常用开关与设置同步保存。

## 全局快捷键

| 默认组合 | 动作 |
| --- | --- |
| Ctrl + Alt + Space | 打开快速聊天并聚焦输入 |
| Ctrl + Alt + H | 显示／隐藏伙伴 |
| Ctrl + Alt + D | 开关免打扰 |
| Ctrl + Alt + P | 开关整体鼠标穿透 |

在设置中修改或禁用。与其他程序冲突时显示提示，保留有效注册；程序退出会释放快捷键。穿透或隐藏后仍可使用托盘，不依赖点击角色恢复。
