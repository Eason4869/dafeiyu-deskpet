安装检查在独立目录执行，先确认没有本项目的已注册安装。测试会保留测试前的自启值，并在退出时恢复；验证没有启用用户实际的自启。卸载后的测试目录只保留故意创建的个人 data。安装器自删除辅助进程可能稍后退出，因此检查会等待其正常清理完成。

源码首次独立打包检查发现脚本依赖未发布的 work 截图，同时 README 头图在安装目录缺失。现在截图和预览图随源码发布，打包只读取公开文件，README 使用源码和运行目录共有的 previews 路径；回归检查已先失败再通过。

本次独立发布审查提出两项修复：安装包在 Package 之后编译会留下缺失或旧的校验项；关闭自启时可能删除同名但属于另一安装位置的值。两项均先观察回归失败，再修复。BuildInstaller 现在编译成功后自动替换该安装包的 SHA256 项；StartupRegistration 删除前比较完整当前程序命令。随后完成用户追加的可编辑代理地址，新增真实路由及 WPF 保存回归检查，全体检查通过。其他版本/设备与真实模型账号仍按以下边界验收。

界面截图来自实际 WPF 窗口；聊天截图中的回复由本地模拟服务提供。原生鼠标检查仅操作测试启动的进程并恢复光标。本次最终原生轮次完整通过；外部鼠标输入会使拖动检查明确跳过，需要在不干扰时重试。

更新客户端的协议、大小与摘要验证已用本地服务检查。正式 GitHub Release 发布后的实际查询与下载校验结果记录在发布说明中。固定仓库为 https://github.com/Eason4869/dafeiyu-deskpet；更新默认需要用户点击检查、下载，再手动退出程序运行安装包。

尚未人工验收：真实 MiMo/Gemini Live 等账号的模型权限、联网可达性和声音质量；混合 DPI 多屏移动、设备热拔插、其他 Windows 版本/驱动和语音包。在线请求格式、本地硬件和安装流程通过不代表这些项目已通过。安装包尚未做应用代码签名。

运行 ZIP 与安装器不包含 data、密钥或聊天记录；源码 ZIP 排除 work、.git、data 和本地执行计划。包装脚本检查高清素材、全部 ZIP 完整性，以及运行 ZIP 内 EXE 与交付 EXE 的 SHA256 一致。模板包含 pet.json / PNG、JSON Schema 和动作网格图；两份高清外观 ZIP 各带独立人格。

保留原 E包设计及高清素材；旧 v1.0、v1.1、v1.2 交付分别备份在本地 outputs/previous-v1.0、previous-v1.1、previous-v1.2，不上传仓库。原运行目录的用户 data 保持保留。
