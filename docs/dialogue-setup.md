# 文字、语音与 Live 设置

右键桌宠 → **打开完整对话** → **连接设置**。设置左侧分别有“人格、对话模型、语音识别、声音与朗读、Live 实时语音”。地址、模型和密钥需点 **保存服务设置**；切换页面保留未保存的草稿。启动不会联网或打开麦克风。

## 文字与人格

在“对话模型”选常用服务预设，或手动填地址、模型、API 密钥。默认 **OpenAI Chat Completions**；兼容 Claude 的服务可选 **Anthropic Messages**。地址保留 /v1 或服务规定的前缀；程序分别拼接 /chat/completions 或 /messages，也接受完整端点。Anthropic 请求使用 x-api-key、anthropic-version、独立 system 与 max_tokens。

远程服务需 HTTPS，本机可用 http://127.0.0.1:端口/v1 且可无密钥。预设是填表的示例，不保证账号拥有该模型；火山部署 ID 与智谱模型需自行填写。MiMo Token Plan 用户可选择国内 Token Plan 预设，使用对应服务的密钥。

每项服务都有 **通过本机代理 127.0.0.1:7890 连接** 开关，默认关闭。开启后需有该 HTTP 代理运行。ASR/TTS 复用文字服务时继承其代理。切换预设或手动改到其他域名、协议、端口时会清空旧密钥；同一服务内修改地址路径可保留密钥。

聊天 Enter 发送、Shift+Enter 换行，每条最多 8000 字；支持停止、复制回复和清空。双击角色可在头顶气泡直接输入，展开聊天查看完整内容。文字完整返回后显示，当前没有逐字流式输出。

每位伙伴各有独立人格与最近 10 轮成功会话。切换伙伴同步切换；正在对话需先停止。E包预设使用用户指定的白发正太人格。编辑只影响当前伙伴；保存或恢复预设后清空当前伙伴上下文。退出后记录不保留。关闭气泡不会取消气泡发起的请求。

## ASR + TTS

“语音识别”填识别模型、协议、地址及密钥。“声音与朗读”选 Windows 系统语音，或打开云端 TTS 并填模型与音色。两项均可独立勾选复用文字服务的地址、密钥和代理，模型仍单独设置。

**MiMo**：协议选自动或 MiMo Chat Audio；识别模型 mimo-v2.5-asr，合成 mimo-v2.5-tts。MiMo 在 /chat/completions 使用音频输入与 Base64 音频输出。音色可用苏打、白桦、冰糖、茉莉或 mimo_default 等服务支持名称。Token Plan 是否开放所用模型以账号权限为准。

**OpenAI Audio**：ASR 上传 WAV multipart 到 /audio/transcriptions，返回 JSON text；TTS 向 /audio/speech 请求 WAV。其他服务须兼容对应协议，不能将只支持文字的模型填进语音页。

聊天选 ASR + TTS，点击 **点击说话** 才打开麦克风。至少说半秒，点击 **结束并发送**：识别 → 文字模型 → 显示文字 → 朗读。最长 60 秒，到时自动发送；停止可放弃录音或请求。麦克风采用 16kHz 单声道 PCM，原录音只在内存。

音量默认 50%，更改立即生效并保存，0% 静音；自动朗读可关闭。试听先保存连接设置并朗读问候。朗读失败保留文字，显示具体服务错误。云端 WAV 临时放在 data/audio-cache，完成或取消时删除。

## Gemini Live

“Live 实时语音”选 Gemini Live 预设，填写自己的模型、密钥、音色（例如 Kore）。完整 WSS 地址：

`wss://generativelanguage.googleapis.com/ws/google.ai.generativelanguage.v1beta.GenerativeService.BidiGenerateContent`

示例模型 gemini-3.8-live，以账号实际可用模型为准。Live 使用原生 WebSocket，与文字页面的 Gemini OpenAI 地址不同。代理单独设置。

聊天选 **Live 实时语音** → **开始 Live**。服务器确认初始化后打开麦克风，持续传输 16kHz PCM，直接播放返回 PCM；显示输入和回复字幕，完成轮次加入当前伙伴记录。语音打断会清除播放缓冲。Live 使用当前伙伴人格，独立建立连接，不自动将原文字聊天历史上传到 Live。

再点 **结束 Live** 或 **停止** 会关闭网络、录音和播放。Live 期间文字、ASR 流程、切换伙伴和语音模式暂停；结束后恢复。关闭发起 Live 的聊天窗口或退出桌宠也会结束 Live。建议使用耳机，避免外放声音被重复拾取。

## 故障定位

401/403：密钥或模型权限；404：地址前缀与模型名；429：额度或频率；MiMo 不返回文字或音频：检查 ASR/TTS 模型、协议和音色。无录音：检查 Windows 默认输入设备及桌面应用麦克风权限。无声音：检查默认输出设备、音量与已安装的中文 Windows 音色。

HTTP 请求含响应体总超时 120 秒，Live 初始化约 25 秒，可随时停止。错误摘要不展示服务原始响应或密钥。密钥由 Windows 当前用户 DPAPI 加密，换机器或账户需重新填写。应用不能读取桌面或自动上传文件；用户发送的文字和录音交给配置的服务。

已用本机模拟 HTTP/WebSocket 与真实默认麦克风/输出设备验证。没有调用真实付费模型、MiMo 在线账户或 Gemini Live 账户；线上权限、网络可达性和声音质量仍需配置后确认。
