Gemini Live 回归先用二进制初始化帧复现用户截图中的“消息格式不受支持或内容过大”，修复后文本与二进制消息均完成真实本地 WebSocket 握手、音频输入、播放和字幕提交，仍限制单条消息为 2 MiB。服务拒绝请求时不向界面泄露响应正文或密钥。

TTS 回归先确认两个对话窗口缺少开关，再验证新控件三处同步、即时保存、等待期间关闭以及合成期间关闭。Live 原生音频与分步 TTS 是独立输出路径，TTS 开关的范围在界面提示和 README 中说明。

安装检查仅使用独立测试目录，测试前确认没有本项目的正式注册安装，并保存、恢复原自启值。旧名称迁移只处理已知文件和目标属于当前安装的快捷方式；自定义开始菜单目录问题先复现，再修复并验证另一安装目标不会被清理。卸载保留用户 data。

README 图示用浏览器渲染检查；截图来自实际 WPF 窗口，聊天回复来自本地模拟服务。LOGO 参考 E包重新生成，导出 16、20、24、32、40、48、64、96、128、256px ICO 并检查小尺寸显示。两套角色素材保持原样，各有 73 帧、480×520 单帧及 3840×5720 透明精灵图。

GitHub 发布后的实际查询、安装包下载和摘要结果见 Release 说明。固定仓库为 `https://github.com/Eason4869/deskpet`。旧 1.3.x 用户需手动安装一次 0.3.1 完成版本编号调整。

尚未人工验收：真实 Gemini Live / MiMo 等账号的权限、联网语音效果、混合 DPI 多屏、设备热拔插、其他 Windows 驱动及语音包。安装器尚未签名。本机协议与硬件检查通过不代表这些项目已通过。
