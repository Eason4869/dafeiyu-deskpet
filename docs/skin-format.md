# 桌宠外观格式 v1

导入入口：设置 → 伙伴与外观 → 导入外观。支持单个透明 PNG，或 `pet.json` 与 PNG 放在同一个文件夹。ZIP 请先解压。仅包含图片、简介和人格，无脚本执行接口。

程序旁 **templates** 文件夹有可直接导入的 `pet.json` + 大肥鱼布局示例 `spritesheet.png`、`pet.schema.json` 格式说明和 `grid-guide.svg` 动作网格示意图。界面展开“如何制作和导入桌宠”后可直接打开。复制模板文件夹，换成自己的图，填写下列字段，再导入。SVG 是制作参考图，不是可导入的 PNG。

```json
{
  "version": 1,
  "name": "我的桌宠",
  "atlas": "spritesheet.png",
  "description": "喜欢写代码的桌面伙伴",
  "system_prompt": "你是我的桌宠，一位温和俏皮的桌面伙伴。用自然的中文回答，保持简洁，如实表达不确定性。你不能直接看见用户桌面，也不会自动读取文件。"
}
```

`atlas` 填同文件夹内 PNG 的文件名；名称最长显示 32 个字符。`description` 可省略，最多 1000 字；`system_prompt` 为预设人格，可省略，最多 8000 字。缺少人格时自动生成以伙伴名称开头的通用设定。选择 `pet.json` 保留名称及人格；直接选择 PNG 时使用文件名与通用人格。图片和模板自动复制到程序旁 `data/skins/skin-<GUID>`。

“人格”页的编辑按桌宠 ID 保存，恢复预设会还原导入时的 `system_prompt`，不影响其他伙伴。切换外观同时切换其人格与内存会话，避免角色混淆。导入同一模板多次会创建不同 ID，可以分别设定。

PNG 必须是 **8 列 × 11 行**等大网格。原 v2 小图可用 1536×2288（单帧 192×208）；高清推荐 3840×5720（单帧 480×520），采用同一角色比例。每帧需要透明背景和可见角色；未使用格保持透明。

| 行（从 1 开始） | 动作 | 有效帧数 |
| --- | --- | --- |
| 1 | 待机 idle | 6 |
| 2 | 向右跑 running-right | 8 |
| 3 | 向左跑 running-left | 8 |
| 4 | 招呼 waving | 4 |
| 5 | 跳跃 jumping | 5 |
| 6 | 委屈 failed | 8 |
| 7 | 等待 waiting | 6 |
| 8 | 思考 running | 6 |
| 9 | 检查成果 review | 6 |
| 10 | 视线 0° 至 157.5° | 8 |
| 11 | 视线 180° 至 337.5° | 8 |

视线角度从正上方开始，顺时针每格 22.5°；90° 朝屏幕右侧，180° 向下，270° 朝屏幕左侧。动作从左到右按播放顺序排列，同组人物比例与地面位置保持一致；跳跃保留实际抬升。画布留出足够边距，头发、手脚及尾巴完整。

文件限 25 MB；单帧宽 64–768、高 64–832 像素，总图限 5500 万像素。尺寸上限用于有界解码；显示比例按 192:208 的标准画布设计。损坏图、缺帧、无透明背景和路径越界会拒绝导入，当前桌宠继续使用。

源码接口：`SkinCatalog.Import(path)` → `SkinDefinition`；`SkinDefinition.Load()` → `SpriteAtlas`；`PetWindow.SelectSkin(skin)` 运行中切换。`SkinCatalog.Skins` 列出内置和已导入的外观，`Find(id)` 根据保存的选择查找。

## 内置动画（0.4.0）

三位伙伴直接使用上述 8×11 高清图的 73 个原始动作及视线帧。已删除 0.3.3 的插值混合补帧，避免叠影；动作直接换帧。窗口渲染与位移仍按显示刷新节奏调度，外观导入格式保持兼容。
