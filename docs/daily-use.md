# 日常使用（0.4.0）

## 聊天历史

设置 → 免打扰与快捷键 → 保存聊天历史，默认开启。文字、ASR 后的对话及 Live 字幕按伙伴保存，恢复时显示以前的记录。完整聊天默认显示最近 50 轮，点击“加载更早记录”继续查看，点击“导出记录”保存 Markdown。清空同时删除当前伙伴的磁盘记录。

每位伙伴保留最近 200 轮且序列化内容最多 8 MiB，超出上限整轮删除最旧记录。模型只收到最近十轮完整成功对话，并按输入长度裁剪；未完成记录仅供查看。Live 打断、停止和异常字幕也保留，标注未完成状态并排除成功上下文。应用异常退出时，最后一次进度检查点恢复为“已中断”。关闭保存后保留已有文件，当前会话仍可在内存中使用。

记录放在程序旁 data/history，使用当前 Windows 用户 DPAPI 加密。换机器或 Windows 账户可能无法解密，原文件会保留并提示；导出的 Markdown 为普通文本。发布包不包含个人 data。保存失败会提示，当前对话继续保留在内存。

## 流式回复

设置 → 对话模型 → 流式回复，默认开启，需点击“保存服务设置”。快速对话和完整聊天共享同一条回复，文字逐步增长；生成期间打开另一窗口可接着查看。向上阅读历史时不强制滚回底部。

点击停止会取消当前请求；断线或服务错误保留已有文字并显示状态。未完成回复不自动朗读，不作为完整的下一轮模型上下文。接口明确不支持流式时可关闭开关。程序不因流式失败自动发送第二次请求。文字完成后按 TTS 偏好与免打扰状态决定是否朗读。

## 免打扰与桌面行为

免打扰暂停主动问候、散步、自动朗读，并停止当前自动朗读；不修改 TTS 输出开关和音量。主动文字、录音及 Live 可继续使用。

全屏自动隐藏默认开启，只检测伙伴所在屏幕的前台全屏应用。退出全屏时仅恢复自动隐藏的伙伴；手动隐藏一直保留。主动唤出快速对话可暂时覆盖全屏隐藏。隐藏时不渲染动画，定时恢复检测仍运行。

整体鼠标穿透让点击落到下方应用，聊天窗口仍可操作；从托盘或快捷键关闭。锁定位置禁止拖动与散步。托盘常用开关与设置同步保存。

## 全局快捷键

| 默认组合 | 动作 |
| --- | --- |
| Ctrl + Alt + Space | 打开快速聊天并聚焦输入 |
| Ctrl + Alt + H | 显示／隐藏伙伴 |
| Ctrl + Alt + D | 开关免打扰 |
| Ctrl + Alt + P | 开关整体鼠标穿透 |

在设置中修改或禁用。与其他程序冲突时显示提示，保留有效注册；程序退出会释放快捷键。穿透或隐藏后仍可使用托盘，不依赖点击角色恢复。
