# 制作自己的桌宠

1. 复制本文件夹到一个新目录。
2. spritesheet.png 是可导入的大肥鱼示例布局，换成自己的 8 列 × 11 行透明 PNG。推荐完整尺寸 3840×5720，每格 480×520。帧顺序看 grid-guide.svg，可以用浏览器打开。
3. 用文本编辑器修改 pet.json 的名称、简介及 system_prompt 人格；atlas 写同目录的 PNG 文件名。
4. 设置 → 伙伴与外观 → 导入外观 → 选择 pet.json。
5. 到“人格”页继续调整。恢复模板预设会恢复导入时的设定。

ZIP 外观包先解压。单独导入 PNG 时，名称取文件名、人格式用通用预设。pet.schema.json 提供字段说明；网格 SVG 只是参考，不能直接导入。

详细教程：../docs/skin-format.md。每行有效帧数：6、8、8、4、5、8、6、6、6、8、8，其余格透明。
