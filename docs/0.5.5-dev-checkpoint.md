# 0.5.5 dev 快照

用户要求于 2026-10-16 按当前进度提交到 dev 并创建 v0.5.5 标签，不创建 GitHub Release、不打包正式安装包。此快照不是 macOS 完成声明。

## Windows 当前改动

- 基于 0.5.4 的四宠素材与互动扩展，33 条新动作、264 帧，8 FPS，不混帧或追赶跳帧。
- 小憩随机选择原坐姿或新版站姿；喂零食和两项专属动作也在新旧版本中随机选择，喂食后的开心保留同一版本。
- 拎起时选择新旧版本，松手后沿用相同版本的普通落地或踉跄；踉跄概率 40%，冷却 10 秒。
- 四种落地共用 0.3 秒的向下位移曲线，标准 208 高画布对应 24 距离，按窗口高度等比例缩放；底部空间不足时截短，不额外抬高拎起。
- 散步等待 90～180 秒；互动后重新计时，速度与距离不变。
- 悬停四选一及节日第五候选接口；空闲睡眠的 5／15 分钟阈值和每分钟 70% 概率保持。

原始动作与重绘动作分别保留。后续优化旧版应保留姿态、动作语义、道具和顺序，只针对透明边缘、色溢及组内对齐；不把动作重设计当作修毛边。旧版第二招牌保留早期生成素材，外观差异和既有边缘问题仍需后续针对性检查，不能宣称已全部消除。

## macOS 当前进度

已获用户批准的 [设计](macos-design.md) 与 [实施计划](macos-implementation-plan.md)：Avalonia 12.1.4 / .NET 10，目标 macOS 14+，分别支持 Apple Silicon 与 Intel，尽量与 Windows 功能对齐。

| 部分 | 快照状态 |
| --- | --- |
| 共用业务 Core | 可编译；11 套原业务测试 221 项和 portable 新增 30 项通过，合计 251 项 |
| Mac 平台托管代码 | 最终源重新编译，0 警告、0 错误，22 项测试通过；包括快捷键释放修正 |
| Mac 原生桥接 | 已有 Keychain、音频、权限、窗口、快捷键、登录项源代码；未在 Mac 上 clang 编译／运行 |
| Avalonia 前端 | 已有入口、素材、桌宠、聊天、队列、厂商和设置初稿；尚未编译，缺 LiveWindow、GuideWindow、AboutWindow，因此当前不能构建完整客户端 |

本机 Windows 工作区安装了隔离的 .NET SDK 10.0.402，下载经 Microsoft 官方 SHA512 验证，没有修改系统 SDK。SDK、NuGet 缓存、测试配置与构建输出都留在忽略的 work 或 bin/obj 中，不进入版本库。

## 验证边界

新增动作、随机候选、睡眠、下落曲线和降低频率的散步单元回归目前为 1005 项通过。较早素材阶段通过的 2882 项回归只代表当时版本，不能用于证明后续新旧随机与物理下落的全部 UI 回归已通过。

原生拖放回归 1445 项通过，逐一验证四宠新旧两套配对和四种落地位移；最初新增断言误把自定义外观也要求为一次随机调用，已改为自定义外观零次。Windows Core/Profile/API/Conversation/Queue 分别 16/86/22/12/24 项通过；0.5.5 本地预览已构建。Mac 真实设备、两架构运行、麦克风权限、多屏、登录项、签名后 Keychain、安装与升级保留数据均待验证。
